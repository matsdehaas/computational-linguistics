# Computational Linguistics

**Python · natural language processing**  
**Course:** Utrecht University · Computational Linguistics

## Overview

Coursework implementing a bigram-based language model and a named-entity recognition pipeline with model training and evaluation.

## Project files

- `bigram-language-model/` — language modeling and generation.
- `named-entity-recognition/` — training and evaluating entity recognition.

## Running the project

Use Python and the original assignment dependencies. The NLP projects may need external datasets or NLTK resources that are not included here.

## Provenance

This repository preserves **original university coursework source files**. The interactive browser adaptations in the portfolio were built later and may use different implementations. No current build or hardware compatibility is guaranteed.
